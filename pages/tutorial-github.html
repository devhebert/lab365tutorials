Git & GitHub

Como Criar um Repositório e Subir Projeto no GitHub

Neste tutorial, você vai aprender a usar Git e GitHub para versionar seus projetos. Vamos desde a instalação e configuração inicial até fazer seu primeiro commit e push para o GitHub.

Passo 1

Instalar o Git

Primeiro, você precisa instalar o Git no seu computador:

Windows

  1. Acesse git-scm.com
  2. Baixe o instalador
  3. Execute o instalador e siga as instruções (pode deixar as opções padrão)
  4. Após instalar, abra o "Git Bash" para usar os comandos

Mac

# Instalar via Homebrew
brew install git

# Ou instalar via Xcode Command Line Tools
xcode-select --install

Linux (Ubuntu/Debian)

sudo apt update
sudo apt install git

Verificar Instalação

git --version
Passo 2

Configurar o Git

Configure seu nome e email (serão usados em todos os commits):

# Configurar nome
git config --global user.name "Seu Nome"

# Configurar email
git config --global user.email "seu.email@exemplo.com"

# Verificar configurações
git config --list
Dica: Use o mesmo email que você vai usar no GitHub para que seus commits sejam associados à sua conta.
Passo 3

Criar Conta no GitHub

Se você ainda não tem uma conta no GitHub:

  1. Acesse github.com
  2. Clique em "Sign Up" no canto superior direito
  3. Preencha os dados:
    • Email (use o mesmo configurado no Git)
    • Senha forte
    • Nome de usuário (será sua URL: github.com/seuusuario)
  4. Verifique seu email
  5. Complete o perfil (opcional, mas recomendado)
Passo 4

Criar um Novo Repositório no GitHub

Agora vamos criar um repositório para hospedar seu projeto:

  1. No GitHub, clique no botão "+" no canto superior direito
  2. Selecione "New repository"
  3. Preencha as informações:
    • Repository name: nome-do-seu-projeto (sem espaços)
    • Description: breve descrição do projeto (opcional)
    • Public/Private: escolha a visibilidade
    • Initialize: NÃO marque nenhuma opção por enquanto
  4. Clique em "Create repository"
Importante: Guarde a URL do repositório que aparece (exemplo: https://github.com/seuusuario/nome-do-projeto.git)
Passo 5

Inicializar Repositório Local

Agora vamos preparar seu projeto local para usar Git:

  1. Abra o terminal/prompt na pasta do seu projeto
  2. Execute os seguintes comandos:
# Inicializar repositório Git
git init

# Adicionar todos os arquivos
git add .

# Criar primeiro commit
git commit -m "Commit inicial"

# Renomear branch para main (padrão atual)
git branch -M main
Explicação dos comandos:
  • git init - Cria um repositório Git na pasta
  • git add . - Adiciona todos os arquivos para serem commitados
  • git commit -m - Cria um commit com uma mensagem
  • git branch -M main - Define o branch principal como "main"
Passo 6

Conectar Repositório Local ao GitHub

Vamos conectar seu repositório local ao GitHub:

# Adicionar repositório remoto
git remote add origin https://github.com/seuusuario/nome-do-projeto.git

# Verificar se foi adicionado
git remote -v
Atenção: Substitua a URL pela URL do seu repositório que você copiou no Passo 4!
Passo 7

Enviar Código para o GitHub (Push)

Finalmente, vamos enviar seu código para o GitHub:

# Enviar código para o GitHub
git push -u origin main

Na primeira vez, o GitHub vai pedir autenticação:

  • Username: seu nome de usuário do GitHub
  • Password: use um Personal Access Token (não a senha da conta)

Como criar um Personal Access Token

  1. No GitHub, vá em Settings (ícone do perfil)
  2. No menu lateral, vá em "Developer settings"
  3. Clique em "Personal access tokens" → "Tokens (classic)"
  4. Clique em "Generate new token" → "Generate new token (classic)"
  5. Dê um nome ao token (ex: "Meu Computador")
  6. Marque a opção "repo" (acesso total aos repositórios)
  7. Clique em "Generate token"
  8. Copie o token (você só verá ele uma vez!)
  9. Use esse token como senha ao fazer push
Sucesso! Seu código agora está no GitHub! Atualize a página do repositório para ver.
Passo 8

Fluxo de Trabalho Diário

Agora que seu projeto está no GitHub, use estes comandos para trabalhar no dia a dia:

Quando fizer alterações no código

# Ver arquivos modificados
git status

# Adicionar arquivos específicos
git add arquivo.html

# Ou adicionar todos os arquivos modificados
git add .

# Fazer commit com mensagem descritiva
git commit -m "Adiciona nova funcionalidade"

# Enviar para o GitHub
git push

Baixar alterações do GitHub

# Se você ou outra pessoa fez alterações no GitHub
git pull

Ver histórico de commits

# Ver histórico completo
git log

# Ver histórico resumido
git log --oneline
Extra

Boas Práticas e Dicas

Mensagens de Commit

Escreva mensagens claras e descritivas:

# Bom
git commit -m "Adiciona formulário de contato"
git commit -m "Corrige bug no menu mobile"
git commit -m "Atualiza estilos da página inicial"

# Ruim
git commit -m "alterações"
git commit -m "fix"
git commit -m "asdfasdf"

Arquivo .gitignore

Crie um arquivo .gitignore na raiz do projeto para ignorar arquivos desnecessários:

# Arquivo .gitignore
node_modules/
.env
.DS_Store
*.log
dist/
build/

README.md

Sempre crie um arquivo README.md para documentar seu projeto:

# Meu Projeto

Descrição breve do projeto.

## Como usar

1. Clone o repositório
2. Abra o index.html
3. Aproveite!

## Tecnologias

- HTML5
- CSS3
- JavaScript

Comandos Úteis

# Desfazer alterações em um arquivo
git checkout -- arquivo.html

# Desfazer último commit (mantém alterações)
git reset --soft HEAD~1

# Ver diferenças antes de commitar
git diff

# Criar e mudar para nova branch
git checkout -b nova-feature

# Clonar um repositório
git clone https://github.com/usuario/repo.git

Solução de Problemas

  • Erro ao fazer push: Certifique-se de ter feito commit antes de push
  • Conflitos de merge: Faça pull antes de push para evitar conflitos
  • Token expirado: Gere um novo Personal Access Token no GitHub
  • Esqueceu de fazer commit: Use git status para ver o que falta

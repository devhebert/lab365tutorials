Deploy

Como Publicar um Site na Vercel com Domínio Próprio

Neste tutorial, você vai aprender como fazer o deploy do seu projeto na Vercel e configurar um domínio personalizado. Vamos seguir um passo a passo completo, desde a criação da conta até seu site estar no ar com domínio próprio.

Passo 1

Criar uma Conta na Vercel

Primeiro, você precisa criar uma conta na Vercel. Siga os passos abaixo:

  1. Acesse vercel.com
  2. Clique em "Sign Up" no canto superior direito
  3. Escolha uma das opções de autenticação:
    • GitHub (recomendado)
    • GitLab
    • Bitbucket
    • Email
  4. Complete o processo de autenticação
  5. Aceite os termos de serviço
Dica: Usar GitHub facilita muito o processo de deploy, já que a Vercel pode acessar seus repositórios automaticamente.
Passo 2

Preparar e Publicar seu Repositório

Antes de fazer o deploy, certifique-se de que seu projeto está em um repositório Git:

  1. Se ainda não tem, crie um repositório no GitHub
  2. Faça upload de todos os arquivos do seu projeto
  3. Certifique-se de que o arquivo principal está na raiz (index.html, por exemplo)
  4. Adicione um arquivo .gitignore se necessário
# Exemplo de estrutura de projeto
meu-projeto/
├── index.html
├── styles.css
├── script.js
├── images/
└── README.md
Passo 3

Fazer Deploy na Vercel

Agora vamos conectar seu repositório à Vercel e fazer o deploy:

  1. No dashboard da Vercel, clique em "New Project"
  2. Clique em "Import Git Repository"
  3. Selecione seu repositório da lista
  4. Configure as opções do projeto:
    • Framework Preset: Selecione o framework usado (ou "Other" para HTML puro)
    • Root Directory: Deixe como "." se os arquivos estão na raiz
    • Build Command: Deixe vazio para projetos estáticos
    • Output Directory: Deixe vazio ou use "." para HTML puro
  5. Clique em "Deploy"
  6. Aguarde o processo de build e deploy (geralmente leva menos de 1 minuto)
Sucesso! Seu site agora está online em um domínio .vercel.app
Passo 4

Comprar um Domínio (Registro.br)

Para ter um domínio personalizado .com.br, você precisa comprá-lo no Registro.br:

  1. Acesse registro.br
  2. Na página inicial, digite o domínio desejado e clique em "Buscar"
  3. Se o domínio estiver disponível, clique em "Registrar"
  4. Crie uma conta ou faça login (será necessário CPF)
  5. Preencha os dados de cadastro:
    • Dados pessoais
    • Endereço
    • Telefone
  6. Escolha o período de registro (1 ano recomendado para começar)
  7. Realize o pagamento via:
    • Cartão de crédito
    • Boleto bancário
    • PIX
Importante: Após a compra, você receberá um email de confirmação. O domínio pode levar algumas horas para ser ativado.
Passo 5

Configurar DNS do Domínio

Agora vamos configurar o DNS no Registro.br para apontar para a Vercel:

  1. Faça login no painel do Registro.br
  2. Vá em "Meus Domínios" e selecione seu domínio
  3. Clique em "Editar Zona" ou "DNS"
  4. Remova todos os registros DNS existentes (se houver)
  5. Adicione os seguintes registros DNS da Vercel: 
    Tipo: A
Nome: @
Valor: 76.76.21.21
TTL: 3600

Tipo: CNAME
Nome: www
Valor: cname.vercel-dns.com
TTL: 3600
  6. Salve as alterações
Atenção: As alterações de DNS podem levar de 4 a 48 horas para propagar completamente, mas geralmente ficam prontas em algumas horas.
Passo 6

Adicionar Domínio na Vercel

Por fim, vamos adicionar seu domínio personalizado no projeto da Vercel:

  1. No dashboard da Vercel, acesse seu projeto
  2. Vá em "Settings" (Configurações)
  3. No menu lateral, clique em "Domains"
  4. Digite seu domínio (exemplo: meusite.com.br) e clique em "Add"
  5. Adicione também a versão com www (www.meusite.com.br)
  6. A Vercel vai verificar a configuração DNS
  7. Aguarde a mensagem de confirmação
  8. Configure redirecionamento (opcional):
    • Marque uma das versões (com ou sem www) como principal
    • A outra será automaticamente redirecionada
Parabéns! Seu site agora está acessível pelo seu domínio personalizado com HTTPS automático!
Extra

Dicas e Solução de Problemas

Certificado SSL

A Vercel automaticamente provisiona um certificado SSL gratuito (HTTPS) para seu domínio. Isso pode levar alguns minutos após adicionar o domínio.

Deploy Automático

Cada vez que você fizer um push no branch principal do seu repositório, a Vercel automaticamente fará um novo deploy. Isso é muito útil para atualizações rápidas!

Problemas Comuns

  • Domínio não funciona: Verifique se os registros DNS estão corretos e aguarde a propagação
  • Erro 404: Certifique-se de que o arquivo index.html está na raiz do projeto
  • Build falhou: Verifique os logs de build na Vercel para identificar o erro
  • CSS/JS não carrega: Verifique os caminhos dos arquivos (devem ser relativos)

Comandos Úteis

# Instalar Vercel CLI (opcional)
npm install -g vercel

# Deploy via CLI
vercel

# Deploy para produção
vercel --prod

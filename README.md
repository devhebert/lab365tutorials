# LAB365 Tutoriais - Guia de Contribuição

## Como Contribuir

1. Faça um fork deste repositório
2. Crie sua branch de tutorial (`git checkout -b tutorial/nome-do-seu-tutorial`)
3. Crie sua página de tutorial
4. Envie um Pull Request

## Criando um Tutorial

### Estrutura de Arquivos

1. Crie um novo arquivo HTML no diretório `pages`
2. Nomeie seu arquivo usando o formato: `tutorial-[nome].html`
   Exemplo: `tutorial-git-basico.html`

### Requisitos da Página de Tutorial

- Use estrutura HTML5 apropriada
- Inclua meta tags descritivas
- Siga os padrões de estilo existentes
- Inclua instruções passo a passo claras
- Adicione exemplos de código quando aplicável

### Atualizando tutorials.html

Depois de criar sua página de tutorial:

1. Abra `pages/tutorials.html`
2. Adicione seu tutorial à lista usando o formato existente
3. Inclua:

- Título do tutorial
- Breve descrição
- Link para sua página de tutorial
- Tag de categoria apropriada

## Diretrizes de Estilo

- Siga as convenções HTML/CSS existentes
- Use elementos HTML semânticos
- Mantenha os princípios de design responsivo
- Teste em diferentes tamanhos de tela

## Dúvidas?

Se você tiver alguma dúvida sobre como contribuir, por favor abra uma issue no repositório.
